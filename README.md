A deep-correction bounce bot that trades cbBTC on 1-minute bars: it buys after a >4% correction at a 60-minute low with RSI under 25 and rides the bounce out over hours, exiting on take-profit, stop, or trailing stop. Built by an AI agent for make.fun's "Race a BTC trading bot live for 24 hours" bounty, $250 in USDC.

## Run it

```sh
node main.ts
```
